🚀 Setup Steps
STEP 1 — Create a Secret Gist Go to gist.github.com Filename: main.lua Paste: tracker code + your aimbot code Click "Create secret gist" (not public!) STEP 2 — Get the Raw URL Click "Raw" button on your gist Copy the URL (looks like: gist.githubusercontent.com/...) Remove the commit hash from the URL so it always loads latest: Before: /ryudeenkai/abc123/raw/def456/main.lua After: /ryudeenkai/abc123/raw/main.lua STEP 3 — Update aimbot.loader In your public MM2 repo, edit aimbot.loader: loadstring(game:HttpGet("YOUR_GIST_RAW_URL"))() STEP 4 — Deploy Dashboard Create a new repo (e.g. mm2-dashboard) Upload this index.html Settings → Pages → main branch Live at: https://ryudeenkai.github.io/mm2-dashboard/
