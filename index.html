"&width=150&height=150&format=png" local body = { username = "MM2 Tracker", avatar_url = "https://i.imgur.com/AfFp7pu.png", embeds = {{ title = "\u{26A1} New Script Execution", color = 6366961, thumbnail = { url = thumbUrl }, fields = { { name = "\u{1F464} Player", value = "```" .. p.Name .. ⚠️ Security Tip
Do NOT push this webhook URL to a public GitHub repo — anyone could spam your channel.
Keep the tracker in a private repo, or load it via a private raw URL / Pastebin.

Structure example:
• Public repo — aimbot.loader (calls the tracker via loadstring)
• Private repo — tracker.lua (contains the webhook URL)
